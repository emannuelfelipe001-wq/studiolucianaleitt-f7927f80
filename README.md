# Studio Luciana Leitte

Crie um site completo para a clínica de estética facial Luciana Leitt Estética.



O site deve ter aparência minimalista, feminina, moderna, profissional, vibrante e premium, usando principalmente rosa suave e branco, com pequenos detalhes em rosa/vermelho e degradês discretos. Evite aparência infantil ou exageradamente rosa.



Tecnologia



Use uma solução leve e rápida, preferencialmente HTML + CSS + JavaScript, sem frameworks ou bibliotecas desnecessárias. O site deve funcionar muito bem no celular, tablet e desktop.

Resultado esperado



O resultado deve parecer um site real e premium de uma clínica estética, e não apenas uma landing page.



Fluxo principal:



Entrar → conhecer a clínica → pesquisar/filtrar procedimentos → adicionar ao carrinho → escolher data e horário → finalizar → abrir WhatsApp com mensagem automática.



Todos os preços, imagens, depoimentos, endereço e informações não fornecidas devem ser tratados como exemplos editáveis.
